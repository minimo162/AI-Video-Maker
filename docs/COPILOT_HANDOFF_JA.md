# Copilotへ動画制作を依頼する

録画から説明に必要な素材を作り、構成・字幕・ナレーション・完成動画の制作をCopilotへ依頼する経路です。アプリは画像・時刻・位置と利用者の説明をまとめます。Copilotへの送信は手動で、完成MP4の作成可否は利用するCopilotの機能・環境に依存します。

## 最初の1本

1. `index.html` をPCのEdgeで開き、「自分の録画を選ぶ」で短いMP4／WebMを選びます。
2. 「Copilotで完成動画を作る」を押します。
3. 見せたい操作・見る人を入力します。「事前に伝えておくこと」には画像だけでは分からない業務の目的、略語、必ず残す説明などを書きます。例：「申請者向け。承認ボタンは管理者だけが使う。最後に申請番号を控える理由を説明したい」。
4. 必要なら画像を作る前に隠す領域を設定し、「出来事画像を作る」を押します。時刻・位置と画像を見て、必要な操作と結果が含まれているか確認します。足りない場合は追加時刻を指定し、画像を作り直します。
5. 「Copilot用PDFを保存」と「動画制作の依頼文をコピー」を押します。ダウンロード一覧からPDFが保存されたことを確認します。
6. 別に開いたCopilotへPDFを添付し、依頼文を貼り付けて送信します。画像から読み取れない箇所は、追加画像や説明で補います。
7. Copilotが作成した動画を保存し、最後まで再生します。文字・数値・操作の順序、字幕・音声の一致、必要な結果が残っているかを確認します。修正点は同じ会話で具体的に伝えます。

この依頼文は完成動画を依頼する通常の文章です。アプリ用の編集案JSONを返す依頼ではなく、回答を「この構成を読み込む」に貼り付ける必要はありません。MP4を作れない環境では、対応環境へ切り替えるか、「アプリで字幕・区間を編集する」を使います。Copilotで動画を作れたことや、PDFのすべての画像が読み取れたことをアプリは判定しません。

## どのファイルを渡すか

| ファイル | 内容と用途 | 注意点 |
|---|---|---|
| Copilot用PDF | 説明と、出来事画像を1ページに1枚ずつ配置。画像ID・時刻・位置と対応させて読むための基本資料 | 画像ページは画像として保存。PDFを開けることだけでは、文字を正確に読めた保証にならない |
| 確認用HTML | 画像を埋め込み、説明と一緒にブラウザーで確認できる単一ファイル | 人の確認用。CopilotによるHTML内の埋め込み画像の解析は未確認 |
| 素材一覧JSON | 目的・視聴者・補足、画像の参照情報、既存の手順の確認済／推定を構造化した補助資料 | 画像本体・元録画は含まない。アプリの作業再開用JSONとは別物 |
| 一覧PNG | 従来のアプリ編集経路でも使う画像一覧 | 一括画像内の文字が小さければ、PDFや詳細画像との比較で確かめる |

PDFの画像は、作成済みの出来事画像から各画像を取り出したものです。同じ画像を小分けに見せることで可読性を確認しやすくしますが、元の録画にない情報や、読めなかった文字を復元するものではありません。画像をHTMLに埋め込むだけでも情報は増えません。画像だけでは分からない目的・理由・用語を利用者が補うことが、説明の追加になります。

## 操作の正確さを保つ

- 画像は録画の一部の瞬間です。画像間でクリック・入力が実際に起きたことまで保証しません。カーソル位置も手がかりであり、クリックの確定情報ではありません。
- 既存の手順リストがあれば、「確認済」「推定」を区別して資料へ含めます。利用者の補足は画像から確認できた事実と分けて扱います。
- 未確認の操作、読めないボタン名・数式・金額、保存成功や作業完了を推測で補わない依頼文にしています。結果は元録画と照合してください。
- 実際の画面の動きを使う場合は、動画入力に対応し、元録画の利用が許可された環境で元録画も別途添付します。PDF・HTML・素材一覧JSONには元録画を同梱しません。静止画だけから元の動きを正確に再現することはできません。

隠す領域は出来事画像と、そこから作るPDF・HTMLの画像に反映されます。**元録画とアプリで保存した完成動画は塗りつぶされません。** 隠す設定を変えたら画像を作り直し、保存前に見直してください。補足の文章や元のファイル名に含まれる情報も自分で確認します。

## アプリで編集する経路も使う

元録画の開始・終了位置や字幕を正確に調整する場合は、「アプリで字幕・区間を編集する」を選びます。従来どおり一覧PNGと編集案の依頼文をCopilotへ渡し、返されたJSONをアプリへ読み込み、字幕と区間を確認します。「動画を作成してダウンロード」でMP4／WebMを保存します。声は任意で、アプリの出力には元録画の音声を使いません。

詳しい編集手順は [初心者向けガイド](GETTING_STARTED_JA.md) と [利用手順](../USER_GUIDE.md) にあります。Copilotへ渡す資料の保存は、アプリで再開するための「作業を保存」とは別です。作業JSONには目的・視聴者を保存しますが、「事前に伝えておくこと」・出来事画像・録画は含まれません。依頼を残すときはPDF／HTML／素材一覧JSONと依頼文も保管してください。

## 比較してから標準の作り方を決める

この経路の実Copilotでの読取・動画制作は未検証です。まず同じ短い非機密の録画で、条件を一つずつ変えて比べます。

1. **完成方法を比較する：** 同じ素材・目的で、Copilotによる直接制作とアプリ編集を試します。正しい操作・結果が残るか、修正回数、手作業の時間、保存した動画が再生できるかを記録します。
2. **入力形式を比較する：** 同じ画像と説明でPNG／PDF／HTMLを用意し、新しい会話で同じ質問をします。「時刻○秒のセル番地・数式・ボタン名」など、説明文に答えを書いていない画像内の情報を尋ね、元録画と照合します。HTML本文に書いた内容を答えられただけでは、埋め込み画像が読めた証拠になりません。
3. **採用範囲を決める：** 概要紹介は直接制作、正確な画面操作はアプリ編集など、確認した結果に応じて使い分けます。形式だけで情報量や正確さが向上したと結論づけません。

12秒の練習用はアプリ内の動画保存の確認です。CopilotによるPDF読取やMP4作成の受入確認とは分けてください。
