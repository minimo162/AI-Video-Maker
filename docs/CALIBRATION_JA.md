# Copilotの可読性の較正（手順書）

出来事画像は、変化した部分を元の解像度のまま切り出し、最大 3888×3438 px の PNG にまとめます（1920×1080 の録画の場合）。ところが Copilot が画像をどこまで縮めてから読んでいるかは公開されていません。縮め方によっては、切り出した文字も、各画像の下の時刻ラベル（24px）も読めなくなります。

この手順では、Copilot が**実際に読める文字の大きさ**を測ります。結果は、出来事画像の大きさ・1枚あたりの画像数・ラベルの文字の大きさ・添付ファイル数の上限（今は20）を決める材料にします。

> **状況（2026-10-15）**：較正シートの生成と採点の道具は用意しましたが、**実際の Copilot ではまだ1度も測っていません**。下の「記録」の欄は空です。

## 用意するもの

- 配布ZIPを展開したフォルダーの `tools/calibration.html`（Edge で開きます。通信はしません）
- 会社で承認されている Microsoft 365 Copilot（画像を添付できる画面）
- 録画は要りません

## 手順

1. `tools/calibration.html` を Edge で開きます。
2. 「シートの大きさ」で次のどれかを選びます。1回の計測で1つです。
   - **本番の最大（3888×3438）**：全画面6枚分。今の出来事画像の最大の大きさです。まずこれを測ります。
   - **全画面2枚分（3888×1146）**：出来事画像が1段だけのときの大きさです。
   - **比較用：全画面1枚だけ（1944×1146）**：今の本番にはない大きさです。1枚あたりの画像数を減らした場合の効果を見るために使います。
3. 「乱数の種」はそのままでかまいません。**採点に同じ種を使うので、メモしておきます。**
4. 「較正PNGを作る」を押し、「較正PNGを保存」で保存します。
5. Copilot で**新しい会話**を開き、較正PNGを**1枚だけ**添付し、ページの「依頼文をコピー」で依頼文を貼り付けて送ります。
6. 回答をすべてコピーし、ページの「Copilotの回答」に貼り付けて「採点する」を押します。シートの大きさと乱数の種は、作ったときと同じにしておきます。
7. 「VALIDATION.md に貼る記録」の文章を、`VALIDATION.md` に貼ります。Copilot の種類（例：職場アカウントの Microsoft 365 Copilot、Edge のサイドバー）も書きます。

ブラウザーを使わずに採点することもできます。回答をテキストファイルに保存して、次を実行します。

    node tools/calibration-score.cjs --seed <乱数の種> --preset full --copilot "Copilotの種類" 回答.txt

`--preset` は `full`（本番の最大）、`two`（2枚分）、`one`（比較用1枚）です。

## 較正シートの中身

- 本番の出来事画像と同じ大きさ・配置です（12px の余白、各枠の下に「元動画 ○秒 ・ 全画面」の 24px のラベル、2列×最大3段）。
- 各枠に、8・10・12・15・18・24px の文字列を、英数字と日本語で2つずつ描きます。枠1つで24件、本番の最大では144件です。
- 文字列は**意味のない乱数**です。モデルが文脈から推測して当てることを防ぐためです。英数字は、字形が紛らわしい文字（0/O、1/I/l、5/S、2/Z、8/B、6/G）を除いています。
- 各文字列の左に 28px の番号（A01 など）、各枠の左上に 48px の通し番号（#1〜#6）を描きます。

## 採点の方法

- **完全一致**：空白・かぎかっこを除き、全角・半角をそろえて（NFKC）、大文字にしてから比べます。
- **文字単位**：1 − 編集距離 ÷ 正解の文字数（0未満は0）。少し読み違えた場合を区別するためです。
- 回答に無い行と「?」の行は「読めない」として0点にします。
- 表（| A01 | 文字列 |）や箇条書き（- A01：文字列）の書式でも読み取ります。
- 時刻ラベルは、小数第1位まで合っていれば正解です。

## 結果の使い方（提案の受け入れ基準）

- Excel の標準の文字（約15px）が、**本番の最大の大きさで完全一致95%以上**なら、今の大きさのままでよいと判断します。
- 下回る場合は、2枚分・1枚分でも測り、95%以上になる大きさを選びます。そのうえで `index.html` の `packSheets` の大きさの定数と、`tests/core.test.cjs` の大きさの上限を、その値に合わせて変えます。
- 時刻ラベル（24px）が読めない場合は、ラベルを大きくするか、各画像に大きな通し番号を描き、依頼文に「番号＝時刻」の対応表を載せる方法を検討します。
- 添付ファイル数の上限（20）が正しいかも、同じ会話で確かめます（20枚添付できるか、21枚目で何が起きるか）。
