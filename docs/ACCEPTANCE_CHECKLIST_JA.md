# 社内PCでの受け入れ確認チェックリスト（字幕のみ）

社内PC・社内の Edge で、字幕のみの経路を最初から最後まで通し、結果を数値で残すためのチェックリストです。判定の表は [ACCEPTANCE.md](../ACCEPTANCE.md)、記録は [VALIDATION.md](../VALIDATION.md) に書きます。この文書は「何を、どの順で、何を記録するか」をまとめたものです。

> **状況（2026-10-15）**：このチェックリストは**まだ実施していません**。自動テストや合成データの結果から合格を推定しないでください。

## 対象

- ACCEPTANCE の S01、T01〜T03、T10、T11（字幕のみの経路）
- 録画は [変化検出の精度ベンチマーク](BENCHMARK_JA.md) で作った**正解付きの録画**を使います。同じ素材を使うと、ベンチマークの結果と実機の結果を比べられます。
- 声あり（VOICEVOX の WAV）の確認は別の回に行います。字幕のみの合格を、声ありの合格として扱いません。

## 始める前に

- [ ] 社内PCに、配布ZIP（`AI-Video-Maker.zip`）を**展開して**置いた（ZIPの中から直接開かない）
- [ ] `index.html` を右クリック →「プログラムから開く」→ Microsoft Edge で開いた（アドレスが `file:///` で始まる）
- [ ] 使う録画3本と正解の CSV が手元にある。録画に機密の情報が写っていない
- [ ] Copilot に画像を渡してよいことを、会社のルールで確認した
- [ ] 記録用に次の環境を書き留めた：PC の機種、Windows の版、Edge の版（`edge://version`）、画面の解像度と拡大率、録画の解像度とコーデック

## 1本ごとの確認（録画3本で繰り返す）

### A. 起動と読み込み（T01）

- [ ] サーバーやインストールなしで画面が開いた。「このブラウザーには…機能がありません」が出ない
- [ ] 録画を読み込めた。長さと解像度が正しく表示された
- [ ] 開発者ツール（F12）の「ネットワーク」タブに、外部への通信が出ていない

### B. 出来事画像（走査）

- [ ] 「出来事画像を作る」を押し、開始前の所要時間の目安を記録した
- [ ] 走査の途中でウィンドウを最小化するか別のタブへ移り、30秒以上たってから戻った。走査が止まらず、続きが進んでいる（または完了している）
- [ ] 終わったときの表示から、**所要時間、走査回数、出来事画像のファイル数、切り出し・全画面の件数、省いた件数、カーソルの検出数**を記録した
- [ ] 「0.5秒刻みの細かい再確認が上限…」の表示が出たか記録した（出た場合はその時刻も）
- [ ] 画像を確認欄で原寸表示し、切り出した部分の文字が読めるか目で確かめた
- [ ] [ベンチマーク](BENCHMARK_JA.md)の手順で、依頼文と正解の CSV を比べ、再現率・誤検出率・途中の状態の捕捉率を記録した

### C. Copilot への受け渡し（S01）

- [ ] 依頼文の横に表示される**文字数**を記録した。目安（8,000文字）を超える警告が出たか記録した
- [ ] 出来事画像を**すべて**添付できた。**添付したファイル数と合計の大きさ（MB）**を記録した
- [ ] 依頼文を貼り付けたとき、末尾（「次の構造のJSON」以降）まで入っていた。途中で切れた場合は、そのときの文字数を記録した
- [ ] Copilot の回答を貼り付けて「この構成を読み込む」を押した。**1回で取り込めたか**、出た警告（前後の文章の除去、null の補正など）を記録した
- [ ] 取り込めなかった場合は、エラーの文と、Copilot に頼み直した回数を記録した
- [ ] **questions の件数**、手順の件数、そのうち「（推定）」の件数を記録した
- [ ] 「次の詳細画像を作る」が出たか。出た場合は2回目の依頼まで行い、その回数を記録した

### D. 字幕と区間の確認

- [ ] 場面と字幕を確認し、**人が直した字幕の数**と、区間（開始・終了）を直した場面の数を記録した
- [ ] 手順書を「手順書をコピー」で取り出し、正解の操作表と比べて、抜けた手順・違う手順の数を記録した

### E. 書き出し（T02・T03・T11）

- [ ] 声は付けずに（字幕のみで）「動画を作成してダウンロード」を押し、**書き出しの形式（MP4／WebM）と所要時間**を記録した
- [ ] 保存した動画を、別のプレーヤー（「メディア プレーヤー」など）で最後まで再生できた。字幕が読める
- [ ] WebM になった場合は、Clipchamp に読み込んで MP4 で書き出せたか記録した
- [ ] 書き出しの途中で別のタブへ移ると中断し、部分的な動画を保存しないこと、戻って再実行できることを確認した（T11）

### F. 保存と再開（T10）

- [ ] 「作業を保存」で作業JSONを保存し、ブラウザーを閉じた
- [ ] もう一度開いて「保存した作業を続ける」で JSON を選び、同じ録画を選び直した。場面・字幕・手順、**見せたい操作と見る人**が戻っている

## 結果の書き方

- **検出**：出来事画像に操作が写っていない、時刻がずれている
- **可読性**：画像に写っているが、Copilot が文字を読めていない
- **回答形式**：Copilot の回答を取り込めない、形式が崩れている
