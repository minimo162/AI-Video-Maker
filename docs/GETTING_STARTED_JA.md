# はじめてのAI Video Maker（プログラミング初心者向け）

このガイドは、画面録画からCopilotへ動画制作を依頼する手順と、アプリで字幕・区間を編集する手順を説明します。アプリの起動にコマンド入力・インストール・APIキーは不要です。Copilotへの依頼には、別に利用できるCopilot環境が必要です。

---

## 1. このツールでできること

- PCの画面録画（MP4またはWebM）を読み込み、画像・時刻・説明をまとめたPDFと依頼文を作り、**Copilotへ完成動画の制作を依頼**します。送信は手動です。MP4を作成できるかは利用するCopilotの機能によって異なります。
- 「アプリで字幕・区間を編集する」を選ぶと、Copilotに編集案を作ってもらい、アプリで確認・修正してMP4／WebMを保存できます。
- アプリ編集で声を付けたいときだけ、**VOICEVOX** などで読み上げ音声（WAV）を作って読み込みます。声なしでも完成します。アプリの動画出力では元録画の音声を使いません。
- アプリの処理はあなたのPCのブラウザー内で行われ、勝手に外部へ送ることはありません。Copilotへ手動で渡した後の処理はCopilot側で行われます。

できないこと：画面を録画する機能はありません。先に録画を用意してください。

## 2. 必要なもの

| 項目 | 必要か | 補足 |
|---|---|---|
| Windows PC と Microsoft Edge | 必要 | 想定環境です。他のブラウザーは未検証です |
| このツールのファイル一式（ZIP） | 必要 | GitHubの [minimo162/AI-Video-Maker](https://github.com/minimo162/AI-Video-Maker) から入手します |
| 画面録画（MP4 / WebM） | 自分の動画を作るとき | 最初の練習では不要です |
| Microsoft 365 Copilot | Copilotへ制作・編集案を依頼するとき | 会社で使えるCopilotを別ウィンドウで開きます。完成動画の作成機能は環境によって異なります |
| VOICEVOX | 声を付けるときだけ | 無料の読み上げソフト。字幕のみなら不要 |
| APIキー・アカウント・環境変数 | **不要** | 設定ファイル（.envなど）もありません |
| Node.js・Python | **不要** | 開発者がテストや配布ZIP作成に使うだけです |

## 3. セットアップ（5分）

1. **ZIPをダウンロードする**
   GitHubのページで緑色の「Code」ボタン →「Download ZIP」を押します。配布担当者からZIPを受け取った場合はそれを使います。
2. **ZIPを展開する**
   ダウンロードしたZIPを右クリック →「すべて展開」。できたフォルダーを開きます。
   ZIPをダブルクリックして中を見るだけでは動きません。必ず展開してください。
3. **アプリを開く**
   フォルダー内の `index.html` を右クリック →「プログラムから開く」→「Microsoft Edge」。
   同じフォルダーの `00_START_HERE.html` を開くと、図付きの案内と「アプリを開く」ボタンがあります。
4. **起動を確認する**
   画面上部に「AI Video Maker」と「1 録画 / 2 場面と字幕 / 3 声（任意） / 4 動画ファイル」の4つの工程が表示されれば成功です。
   「アプリを準備しています」から進まない、文字だけのページが出る、という場合は手順3をやり直してください。

フォルダーの中で開くのは `index.html` だけです。`tests`、`scripts`、`prototype.html` は開発用なので触らなくて構いません。

## 4. 最初の実行例：12秒の練習用で動画を保存する

自分の録画やCopilotを使わずに、「動画を作成してダウンロード」を押して保存するところまでを体験できます。

1. 画面の「**12秒の練習用で試す**」を押します。
   ツールが約12秒の合成動画と短いテスト音を作ります。数十秒かかります。このタブを表示したまま待ってください。
2. 準備ができると自動で工程④「動画ファイル」に移ります。「**先頭から再生**」を押します。
   2つの場面が約6秒ごとに切り替わり、字幕と枠・拡大、短い「ピッ」という音が入ります。
3. 「**動画を作成してダウンロード**」を押します。
   動画と同じ約12秒かかります。処理中は他のタブに切り替えないでください（切り替えると中断します）。
4. 「動画のダウンロードを開始しました」と出たら、Edgeの右上のダウンロード一覧からファイルを開きます。

**期待される結果**

- `video-2026-…mp4`（または `.webm`）というファイルが保存されます。
- 再生すると、約12秒、画面サイズ1280×720、2つの場面、濃い色の帯に白い文字の字幕、場面1で枠、場面2で拡大、最後に「合成テスト音（VOICEVOX素材は未使用）」のクレジットが表示されます。
- 拡張子が `.webm` の場合も失敗ではありません。MP4で記録できない環境ではWebMで保存する仕組みです。

ここまで通れば、PCとEdgeで動画が作れる環境です。練習用の素材を保存する必要はありません。

## 5. 自分の録画からCopilotへ動画制作を依頼する

1. 「**自分の録画を選ぶ**」で短い録画を選び、「**Copilotで完成動画を作る**」を押します。
2. 見せたい操作・見る人を入力します。「**事前に伝えておくこと**」には、画像だけでは分からない目的、用語、必ず伝えたい点を書きます。
3. 「**出来事画像を作る**」を押し、画像と時刻を確認します。隠す領域が必要なら画像を作る前に設定してください。
4. 「**Copilot用PDFを保存**」と「**動画制作の依頼文をコピー**」を押します。
5. 別に開いたCopilotへPDFを添付し、依頼文を貼り付けて送ります。PDFには元録画は入りません。実際の動きも使う場合は、対応し、利用が許可された環境で元録画を別途渡します。
6. Copilotが作った動画を保存し、操作・字幕・音声・最後までの再生を確認します。完成動画をアプリへ戻す必要はありません。

「**確認用HTMLを保存**」は画像と説明を人が確認するための単一ファイルです。HTML内の画像をCopilotが解析するかは未確認です。「素材一覧JSONを保存」は補助資料で、作業再開用JSONではありません。詳しい使い分けと試し方は [Copilotへの受け渡しガイド](COPILOT_HANDOFF_JA.md) にあります。

画像だけで、画像の間に起きた操作まで確定できるわけではありません。動画を作成できない場合や区間・字幕を正確に調整したい場合は、次のアプリ編集を使います。

## 6. アプリで字幕・区間を編集して保存する

### 6-1. 録画を用意する

Windowsの「Snipping Tool」（切り取り＆スケッチ）の録画機能などで、説明したい操作を短く録画し、MP4で保存します。最初は**1〜3分の、機密情報が映っていない画面**がおすすめです。

### 6-2. 録画を読み込む

1. ツールの「**自分の録画を選ぶ**」で録画ファイルを選びます。読み込みに数秒〜数十秒かかります。
2. 「**アプリで字幕・区間を編集する**」を押します。
3. 「見せたい操作」に、何を説明する動画かをひと言入力します。例：「出張の申請を、検索から登録まで説明したい」。

### 6-3. Copilotに見せる画像を作る

1. 「**出来事画像を作る**」を押します。ツールが録画全体を調べて、画面が変わった時刻と場所を自動で見つけ、変わった部分を元の大きさのまま切り出したPNG（最大20ファイル）を作ります。手順を自分で書く必要はありません。長い録画ほど時間がかかります。
2. 表示された「一覧PNG 1を保存」「一覧PNG 2を保存」…の**リンクを1つずつ押して**保存します。押していないリンクがあると、画面下の案内が「次の一覧PNGをダウンロード」のままになります。

### 6-4. Copilotに編集案を依頼する（ツールの外の作業）

1. 画面下の案内「次へ：場面と字幕」で工程②へ進みます。
2. 「**依頼文をコピー**」を押します。
3. 別のウィンドウで Microsoft 365 Copilot を開き、保存した一覧PNGを**すべて添付**し、コピーした依頼文を貼り付けて送信します。
4. Copilotが、作業の手順リストと、場面分け・字幕・読み上げ原稿を含む **JSON**（コードのような文字列）を返します。

### 6-5. 回答をツールに戻す

1. Copilotの回答のコード部分を「コードをコピー」などでコピーします。
2. ツールの「Copilotの回答をここに貼り付けます」欄に貼り、「**この構成を読み込む**」を押します。JSONの中身を自分で書き換える必要はありません。
3. 画面に場面カードが並びます。字幕と「使う部分の開始／終了（秒）」を確認し、必要なら直します。
   「Copilotの確認事項」が出たら目を通します。読み上げ原稿は、声を付けないなら無視して構いません。

読み込むと、場面カードの上に「手順リスト」も表示されます。「手順書をコピー」で、そのまま手順書として使えます。録画が長くても、依頼は**通常1回**です。Copilotが読めなかった箇所を回答に書いた場合だけ「次の詳細画像を作る」が表示されます。押して作られたPNG（`detail-01.png` など）を保存し、**同じCopilotの会話**に次の依頼文と一緒に送ってください。

### 6-6. 確認して保存する

1. 「**字幕の動画を確認する**」で工程④へ進みます。
2. 「先頭から再生」でプレビューを確認します。
3. 「**動画を作成してダウンロード**」を押し、タブを表示したまま待ちます。
4. 保存した動画を開き、字幕・場面の切り替え・最後まで再生できることを確認します。

**期待される結果**：元の録画から選んだ区間がつながり、各場面に字幕帯が付いた動画ができます。元の録画の音声は入りません（字幕のみでも、時刻を保つための無音の音声トラックは含まれます）。

## 7. アプリ編集で声を付けたいとき（任意）

1. 工程②の「**声を付ける（任意・VOICEVOXなど）**」にチェックを入れます。
2. 工程③で「台本をコピー」（場面が1つなら「読み上げる本文だけをコピー」）を押します。
3. VOICEVOXで話者を選び、本文を貼り付けて再生で確認し、**WAV形式**で書き出します。
   場面が複数あるときは、ファイル名に場面IDを付けます。例：`s001.wav`、`s002.wav`。台本の「【s001 → s001.wav】」は管理用の見出しなので読み上げには貼りません。
4. ツールの「**WAVファイルを選ぶ**」でWAVを読み込みます。名前が場面IDに合えば自動で対応します。
5. 工程④の「声の表記（VOICEVOXの話者名）」に、使った話者名を入力します（利用規約上のクレジット表記です）。
6. あとは字幕のみと同じく、再生して確認し、動画を保存します。

原稿を直したら、その場面の声は作り直して読み込み直してください。作り直すまで再生・保存はできません。

## 8. 作業を途中でやめる・続きから再開する

- 「**作業を保存**」（画面右上）で、場面・字幕などの編集データをJSONファイルとしてダウンロードします。**自動保存はありません。**
- JSONには動画やWAVは入りません。同じフォルダーに、元の録画（声ありならWAVも）を一緒に保管してください。
- 再開するときは「**保存した作業を続ける**」でJSONを開き、案内に従って同じ録画（とWAV）を選び直します。
- 目的・見る人は作業JSONに保存します。「事前に伝えておくこと」と出来事画像は含まれないため、Copilotへの依頼はPDF・HTML・素材一覧JSONと依頼文も別途保管してください。

## 9. トラブルシューティング FAQ

**Q. CopilotからMP4ではなく文章が返ってきた。**
A. Copilotの動画作成機能・利用可能な形式は環境によって異なります。このアプリはCopilotへ自動接続せず、MP4の作成成功を保証しません。使える機能を確認するか、「アプリで字幕・区間を編集する」から編集案を依頼し、アプリで保存してください。

**Q. PDF・HTMLで情報は増える？**
A. 画像に添えた目的・時刻・位置・補足は文脈になりますが、同じ画像をPDFやHTMLに格納するだけで新しい画面情報が増えるわけではありません。HTML内の埋め込み画像がCopilotで読めるかは未確認です。小さい文字は元録画と照合してください。

**Q. `index.html` を開いたら、文字やコードだけのページになった。**
A. Edge以外のプログラム（メモ帳など）で開いています。`index.html` を右クリック →「プログラムから開く」→ Microsoft Edge を選んでください。ZIPを展開せずに中から開いている場合も失敗します。

**Q. 「この環境では編集を開始できません」「音声処理の機能がありません」と出る。**
A. ブラウザーの音声機能（Web Audio）が使えない環境です。字幕のみの動画でもこの機能を使います。PCのEdgeで開き直し、それでも出る場合は会社の設定の可能性があるので管理担当者に相談してください。

**Q. 「このブラウザーには動画保存に必要な機能がありません」と出る。**
A. 動画の記録機能（MediaRecorder）が使えない環境です。編集と作業JSONの保存はできるので、JSONを保存して対応するPCのEdgeで続けてください。

**Q. 動画の作成中に止まって「タブが非表示になりました」と出た。**
A. 処理中に別のタブやウィンドウへ切り替えると、安全のため中断し、途中までのファイルは保存しません。編集内容は残っています。タブを表示したまま、もう一度「動画を作成してダウンロード」を押してください。

**Q. 保存された動画が `.webm` だった。MP4がほしい。**
A. お使いの環境でMP4の記録に失敗したときはWebMで保存します。MP4が必要なら、WebMをClipchampなどの動画編集アプリに読み込んでMP4で書き出してください。拡張子を書き換えるだけでは再生できません。

**Q. Copilotの回答を貼ったら「JSONを取り込めません」と出る。**
A. 回答の前後の説明文は、アプリが自動で取り除いて読み込みます（そのときは警告が出ます）。それでも出る場合は、コードが途中で切れているか、コードが2つ以上あります。回答の「コードをコピー」で、最初の `{` から最後の `}` までをコピーし直してください。文章だけの回答なら、同じ会話で「指定したJSON形式で回答してください」と頼みます。

**Q. 「次の詳細画像を作る」が出た。必ず押す必要がある？**
A. 必須ではありません。Copilotが画像で読めなかった箇所（数式やダイアログの文字など）があるという合図です。押すとその範囲の高解像度画像が作られるので、保存して同じCopilotの会話で次の依頼を送ると、手順の「（推定）」が確認済みに変わります。

**Q. 「出来事画像を作る」がなかなか終わらない。**
A. 長い録画は全体を千か所以上確認するため、数分かかることがあります。「録画全体を確認中 N / M」の数字が進んでいれば動いています。待っている間に別のタブでCopilotを開いて準備しても、画像の作成は止まりません（表示に戻すと速く進みます）。止めたいときは「処理を中止」を押します。

**Q. WAVを読み込んだのに「手動対応付けが必要です」と出る。**
A. ファイル名に場面IDが含まれていないときの表示です。「どの場面の音声ですか？」の欄で場面を選ぶか、ファイル名を `s001.wav` のように直して選び直してください。MP3など、WAV以外のファイルは読み込めません。

**Q. 「ナレーション音声の再生成または内容確認が必要です」と出て再生できない。**
A. WAVを作った後に原稿を直したためです。VOICEVOXで作り直して読み込み直すか、内容が同じと確認できるなら「現在の台本と同じ音声内容と確認」を押します。

**Q. 保存したJSONを開いたら「録画を選び直してください」と出る。**
A. 正常です。JSONには動画が入っていないので、保存時と同じ録画ファイルを選び直します。別名で保存し直した録画は「差し替え」扱いになり、区間の再確認を求められます。

**Q. ダウンロードを押したのにファイルが見つからない。**
A. 「ダウンロードを開始しました」は、Edgeに保存を頼んだ段階です。Edgeの右上のダウンロード一覧を開き、ブロックされていないか確認してください。動画は工程④に残る「もう一度ダウンロード」から再度保存できます。

**Q. 機密の画面をCopilotに送ってよいか不安。**
A. ツール自体は何も送信しません。画像・PDFなどをCopilotに渡すのはあなたの操作なので、会社のルールに従ってください。氏名や金額など見せたくない部分があるときは、出来事画像を作る前に「注目させたいところ・隠したいところを決める」で囲み、「囲んだところを隠す」を押します。画像と、その画像を使うPDF・HTMLでは塗りつぶされます。元録画とアプリで保存した完成動画は塗りつぶされません。保存前に確認欄で隠れているか確かめてください。
