# AI Video Maker

初めての方は [初心者向けガイド（docs/GETTING_STARTED_JA.md）](docs/GETTING_STARTED_JA.md) からどうぞ。

横長のまま、基本は5分を目安に重要な操作と結果を残す手順動画を作ります。待ち時間・繰り返し・寄り道を削り、説明しきれない場合は操作の目的ごとの分割を提案します。アプリが録画全体を走査して画面が変わった時刻と場所を自動で見つけ、変化した部分を元の解像度のまま切り出した「出来事画像」を作ります。Copilotはそれを読んで作業の手順リストを作り、手順に沿った場面と字幕を返します。長い録画でも通常は1回の依頼です。読めなかった箇所があるときだけ、その範囲の追加画像を同じ会話で渡します。手順リストはそのまま手順書としてコピー・保存できます。声は任意です。


## 自分の録画で最初の1本

録画を選んだら「Copilotで字幕の下書きを作る」で始めます。説明したい操作をひと言入力し、画面の案内に沿って画像一覧と依頼文をCopilotへ渡すと、場面分け・字幕・読み上げ原稿を下書きします。回答をアプリへ戻して字幕と区間を確認し、そのまま声なしでプレビュー・動画保存できます。原稿の自作やVOICEVOXは不要です。Copilotへの受け渡しは手動で、元の録画音声は使いません。

声を付けたい場合だけ「声を付ける（任意）」を選び、Copilotが作った原稿をVOICEVOXなどへ渡してWAVを読み込みます。声付き動画や手動編集の既存ルートも「別の作り方を選ぶ」から利用できます。詳しい手順はUSER_GUIDE.mdを参照してください。

## 使い始める

最初は [はじめに（HTML）](00_START_HERE.html) または [短い手順（TXT）](00_START_HERE.txt) を開いてください。インストールやコマンド入力は不要です。

1. ダウンロードしたZIPを右クリックし、「すべて展開」。取り出したAI-Video-Makerフォルダーを開きます。
2. index.htmlを右クリック →「プログラムから開く」→「Microsoft Edge」。メールやファイルサービス内のプレビューでは使いません。
3. 「12秒の練習用で試す」を押します。自分の録画・音声は不要で、準備後は720pの完成確認へ進みます。
4. 「先頭から再生」で音と字幕を確認し、「動画を作って保存」を押します。処理中はタブを表示したまま待ちます。
5. ブラウザーのダウンロード一覧から保存した動画を開き、音・字幕・場面切替を確認します。

練習素材の保存は不要です。続きから再開したい場合だけ、「作業を保存」と④の「練習用の素材を保存する」から録画・WAVを個別保存します。自動保存はありません。

起動できない場合は画面の案内を確認してください。必要な音声・動画機能がない環境は先に案内し、実行できない練習操作を無効にします。実際の録画・コーデックの合格を保証する確認ではありません。

練習の後は、[利用手順](USER_GUIDE.md)を参考に非機密の短い実録画で字幕のみの経路を試し、声を付ける場合は音声付き経路も試します。詳細な受入試験は[受入チェック](ACCEPTANCE.md)に分けています。

## ひと目で流れを確認する

最初に「元の録画 → 字幕・枠つき」の見本を表示します。架空の申請画面による説明図で、再生できる完成動画ではありません。録画を選ぶと同じ「できあがる動画」欄が自分の素材へ変わり、場面・字幕・効果・声の準備状況が増えていきます。

各工程の編集欄の下にある「次にやること」が、画像作成、PNGのダウンロード、回答の読込、台本コピー、WAV選択、動画保存など、その時点の操作を1つ案内します。長い画面では同じ操作を画面下端にも表示するため、上へ戻らず続けられます。編集欄の下のボタンが見えているとき、文字入力中、背の低い画面や拡大表示では通常配置を使います。処理中は同じ位置が中止ボタンに変わります。

「工程の移動・途中確認」を開くと、準備が途中でも次の工程を確認できます。Copilotを使わない経路は①の「Copilotを使わずに作る」内です。細かい領域設定とTXT保存は必要なときに開きます。狭い画面では編集欄の後にプレビューを表示します。

1. **録画**：「自分の録画を選ぶ」から開始。説明したい操作を書き、Copilotに渡す画像を作ります。
2. **場面と字幕**：画像と依頼文をCopilotへ渡し、返った回答を貼り付けます。場面ごとの短い字幕を確認します。声を付ける場合は読み上げ原稿も確認します。
3. **声（任意）**：字幕のみならこの工程を飛ばします。声を付ける場合だけ台本をVOICEVOXなどへ渡し、場面ごとに作ったWAVを読み込みます。
4. **動画ファイル**：合成プレビューを確認し、MP4またはWebMを作成・ダウンロードします。再生・書き出しの中止はプレビュー横にあります。

CopilotとVOICEVOXは「アプリの外」と明記した手作業です。コピーや画像生成だけでは送信・保存は完了しません。画像ごとのリンクを押し、保存結果はブラウザーで確認してください。元動画の確認、区間・効果の詳細、依頼文・台本の本文、画質・形式は必要なときに開きます。

入力エラーは操作箇所に表示し、素材不足・録画差し替え・台本変更時は次の修正を案内します。声ありでは、動画ファイル工程でWAV不足や原稿変更による再生成の必要を確認でき、解消するまで再生・出力できません。字幕のみではWAVも読み上げ原稿の編集も不要です。どちらも録画・区間・字幕などの入力条件を満たす必要があります。

「保存した作業を続ける」は編集データJSONの再開用です。自動保存はありません。JSONのダウンロード開始と実際の端末への保存は別のため、ブラウザーで保存結果を確認してください。動画・WAVと、Copilot依頼用の目的・視聴者はJSONに含まれません。

## 配布・作業の持ち運び

利用に必要なのはindex.htmlだけです。00_START_HERE.html／.txtとREADME・USER_GUIDEは案内用、tests・scripts・prototype.htmlは開発・動作確認用です。最初に開くアプリはindex.htmlです。作業を再開・移動するときは、保存した作業JSONと元の録画、声ありの場合は各場面のWAVを別途保管・配布してください。JSONだけでは素材は戻りません。

## 画面の文字とフォント

画面の本文は18px、説明文・通知は主に16px、補助ラベルは15px以上です。入力欄・主要な操作ボタンも読みやすい大きさにし、狭い画面では工程を2列にして操作を折り返します。

UIは端末にある **BIZ UDPゴシック**（CSS名：BIZ UDPGothic）を優先します。未導入・ブラウザーから利用できない場合は游ゴシック、メイリオ等に代替します。MicrosoftではWindowsの日本語補助フォントとして案内されていますが、すべての端末にあるとは限りません。[Microsoftのフォント情報](https://learn.microsoft.com/en-us/typography/font-list/biz-udgothic)

フォントファイルの同梱・外部フォントの読込はしません。端末のフォント名をCSSで指定する方式です。[MicrosoftのWeb利用説明](https://learn.microsoft.com/en-us/typography/fonts/font-faq#web) 実際に選ばれるフォントと画面上の収まりは未検証です。

画面の配色・部品は白と淡いグレーを基調とし、現在の工程と主操作を緑で示します。入力枠・ボタン・パネルの余白と角丸を統一し、プレビューは濃色の枠にまとめています。背の低い画面ではプレビューを固定せず、停止ボタンやエラーへスクロールできる配置にします。実際の画面の収まりは未確認です。

## 実装範囲

- 録画全体を0.5〜2秒間隔で走査し、変化した時刻は0.5秒刻みで再走査。16pxの区画ごとの差分から、変化した時刻と画面上の場所を求める
- 局所的な変化は元の解像度のまま切り出し（最小640×360）、全画面の変化・一定間隔・指定時刻は全画面で、時刻順に最大20ファイルの出来事画像（events-01.png〜）へまとめる。上限を超える場合は変化の弱いものから省く
- 走査中は経過時間と残り時間の目安を表示し、終了時に切り出し・全画面の件数、上限で省いた件数、走査回数、所要時間、60秒以上変化のなかった区間を表示する
- 画面が変わる直前の原寸フレームからWindowsの矢印カーソルとExcelの白い十字カーソルを自動で探し、出来事画像に赤丸で示す。カーソルが切り出しの外にあるときは、その周辺を原寸で切り出した画像（種類「カーソル」）を追加し、出来事一覧に位置を載せる。カーソルが録画に写っていない場合や形が異なる場合は検出しない
- 作った画像を画面内で縮小表示し、押すと別タブで原寸表示する
- Edgeでは保存先フォルダーを1回選ぶと、全画像を新しいサブフォルダー（出来事画像-日時）へまとめて保存する。使えない環境では従来どおり1ファイルずつのリンクで保存する
- 依頼文に出来事一覧（時刻・ファイル名・種類・画面上の位置）を含め、Copilotに手順リスト（steps：確認済／推定、時刻、操作の説明）と、手順に対応する場面（stepId）を1回で返させる
- 手順リストを画面に表示し、手順書としてコピー・TXT保存。場面のない回答は時刻のある手順から場面を作る
- 回答の `nextRanges`（読めなかった箇所）だけを0.5秒ごとに走査した詳細画像（2枚ずつのPNG）で追加確認できる
- 社内Microsoft 365 Copilotへ手動添付する依頼文と、編集案JSONの検証
- IDによる場面別WAV対応、重複確認・手動対応・試聴
- 元動画の開始／終了ボタン、±0.1／±1秒、字幕・領域編集、並べ替え・削除・取消
- ナレーション変更時の音声再生成状態、字幕はみ出し検知
- 声ありはAudioContext、字幕のみは元映像の再生位置を基準に進行（末尾の静止部分のみ単調増加時計）。2つの動画要素による次場面準備、共通Canvas描画
- CanvasとWeb AudioをMediaRecorderへ渡す実時間書き出し
- 最初の書き出し前に短い合成映像・音声を記録し、映像の再生時刻が進む形式を選択
- MP4本番記録の失敗時は、部分出力を破棄してWebMで最初から自動再試行
- MP4はH.264／AACを指定して記録できる場合だけ作成し、それ以外はWebMで保存
- 実MIMEに合う拡張子、出力後の映像デコード確認
- プロジェクトJSON保存・復元、素材の再選択とメタデータ照合

声ありの場面尺は max(映像長, 0.15秒＋WAV長＋0.25秒)、字幕のみは max(映像長, 0.4秒) です。字幕のみでは保持中のWAVを再生せず、尺にも使いません。どちらも録画元音声は合成しません。声ありではWAVの無音も長さに含みます。字幕のみの書き出しにも時刻維持用の無音トラックを含むため、音声トラックがないファイルという意味ではありません。

動画の読込・シーク・コーデック・MediaRecorderの対応は端末に依存します。フレーム欠落ゼロ、フレーム単位編集、±150msの同期を保証するものではありません。保存前のデコード確認は映像が読めることの確認であり、音声の聴取確認やClipchamp互換確認の代替にはなりません。

## 開発と検証

アプリには依存パッケージがありません。リポジトリのルートで次を実行すると、全テストを一括実行できます。Node.js 22 では `node --test tests/` だけでは `.cjs` が拾われないため、ワイルドカード付きのパスを指定します。Node.jsに加え、配布ZIPのテストにはPython 3（`python3`、`python`、`py -3` の順に確認）が必要です。Python 3 が見つからない環境では配布ZIPのテストをスキップし、その旨を表示します。

    node --test tests/*.cjs

Windows の PowerShell でも同じコマンドで動きます（`node --test tests\*.cjs` でも可）。

個別に実行する場合は次のコマンドを使います。

    node tests/core.test.cjs
    node tests/editor.test.cjs
    node tests/media-controller.test.cjs
    node tests/workflow.test.cjs
    node tests/readability.test.cjs
    node tests/navigation.test.cjs
    node tests/detail-pass.test.cjs
    node tests/package.test.cjs
