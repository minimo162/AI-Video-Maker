# AI Video Maker

操作録画に、場面別のWAV・字幕・拡大・強調を付ける日本語のローカル動画編集アプリです。実行に必要なのは **index.html 1ファイル**です。CDN、外部API、外部フォント、テレメトリ、サーバー、インストールは使いません。

**実験版です。実ブラウザでの動画書き出しは未検証です。** 利用している検証環境でローカルアプリへのブラウザーアクセスが制限され、12秒の実機試験を実施できていません。社内Edge、Snipping Toolの実MP4、実VOICEVOX WAV、Clipchamp変換、90秒の同期は受入確認が必要です。自動検証を実機合格と扱わないでください。

## 使い始める

1. ZIPを展開し、index.html をMicrosoft Edgeで開きます。
2. 最初の画面の「12秒の練習用で試す」で2場面の合成素材を生成します。別途生成された録画とWAVも保存します。
3. ④でプレビューし、音声付き動画を書き出します。白いマーカーと短音・字幕・拡大・場面切替を確認します。
4. 試験が通ってから、実際のSnipping Tool MP4とVOICEVOX WAVで同じ試験を行います。MP4が出せない場合はWebMを選び、Clipchampで取込とMP4変換を確認します。
5. 通常の作業は [利用手順](USER_GUIDE.md) を参照してください。確認記録は [受入チェック](ACCEPTANCE.md) に残してください。

## ひと目で流れを確認する

最初に「元の録画 → 字幕・枠つき」の見本を表示します。架空の申請画面による説明図で、再生できる完成動画ではありません。録画を選ぶと同じ「できあがる動画」欄が自分の素材へ変わり、場面・字幕・効果・声の準備状況が増えていきます。

画面上の「次にやること」は、画像作成、画像のダウンロード、構成の読込、台本コピー、WAV選択、動画保存など、その時点の操作を1つ案内します。下の通常操作も使え、Copilotを使わずに自分で場面を作ることもできます。

1. **録画**：「自分の録画を選ぶ」から開始。説明したい操作を書き、Copilotに渡す画像を作ります。
2. **場面と字幕**：画像と依頼文をCopilotへ渡し、返った回答を貼り付けます。場面ごとの短い字幕と、声で伝える説明を整えます。
3. **声**：台本をVOICEVOXへ渡し、場面ごとに作ったWAVを読み込みます。
4. **動画ファイル**：合成プレビューを確認し、MP4またはWebMを作成・ダウンロードします。再生・書き出しの中止はプレビュー横にあります。

CopilotとVOICEVOXは「アプリの外」と明記した手作業です。コピーや画像生成だけでは送信・保存は完了しません。画像ごとのリンクを押し、保存結果はブラウザーで確認してください。元動画の確認、区間・効果の詳細、依頼文・台本の本文、画質・形式は必要なときに開きます。

入力エラーは操作箇所に表示し、素材不足・録画差し替え・台本変更時は次の修正を案内します。音声不足でも動画ファイル工程で不足を確認できますが、素材が揃うまで再生と出力はできません。

「保存した作業を続ける」は編集データJSONの再開用です。自動保存はありません。JSONのダウンロード開始と実際の端末への保存は別のため、ブラウザーで保存結果を確認してください。動画・WAVと、Copilot依頼用の目的・視聴者・希望尺はJSONに含まれません。

## 配布・作業の持ち運び

利用に必要なのはindex.htmlだけです。READMEやUSER_GUIDEは案内用、testsとprototype.htmlは開発・動作確認用です。作業を再開・移動するときは、保存したproject.jsonと元の録画、各場面のWAVを別途保管・配布してください。JSONだけでは素材は戻りません。

## 画面の文字とフォント

画面の本文は18px、説明文・通知は主に16px、補助ラベルは15px以上です。入力欄・主要な操作ボタンも読みやすい大きさにし、狭い画面では工程を2列にして操作を折り返します。

UIは端末にある **BIZ UDPゴシック**（CSS名：BIZ UDPGothic）を優先します。未導入・ブラウザーから利用できない場合は游ゴシック、メイリオ等に代替します。MicrosoftではWindowsの日本語補助フォントとして案内されていますが、すべての端末にあるとは限りません。[Microsoftのフォント情報](https://learn.microsoft.com/en-us/typography/font-list/biz-udgothic)

フォントファイルの同梱・外部フォントの読込はしません。端末のフォント名をCSSで指定する方式です。[MicrosoftのWeb利用説明](https://learn.microsoft.com/en-us/typography/fonts/font-faq#web) 実際に選ばれるフォントと画面上の収まりは未検証です。

## 実装範囲

- 3秒間隔と指定時刻の代表画像、最大48枚、6枚ずつのPNG一覧
- 社内Microsoft 365 Copilotへ手動添付する依頼文と、編集案JSONの検証
- IDによる場面別WAV対応、重複確認・手動対応・試聴
- 元動画の開始／終了ボタン、±0.1／±1秒、字幕・領域編集、並べ替え・削除・取消
- ナレーション変更時の音声再生成状態、字幕はみ出し検知
- AudioContext主時計、2つの動画要素による次場面準備、共通Canvas描画
- CanvasとWeb AudioをMediaRecorderへ渡す実時間書き出し
- 最初の書き出し前に短い合成映像・音声を記録し、映像の再生時刻が進む形式を選択
- MP4本番記録の失敗時は、部分出力を破棄してWebMで最初から自動再試行
- 実MIMEに合う拡張子、出力後の映像デコード確認
- プロジェクトJSON保存・復元、素材の再選択とメタデータ照合

映像と音声の長さを比べ、場面尺は max(映像長, 0.15秒＋WAV長＋0.25秒) です。録画元音声は合成しません。WAVの無音も長さに含みます。

動画の読込・シーク・コーデック・MediaRecorderの対応は端末に依存します。フレーム欠落ゼロ、フレーム単位編集、±150msの同期を保証するものではありません。保存前のデコード確認は映像が読めることの確認であり、音声の聴取確認やClipchamp互換確認の代替にはなりません。

## 開発と検証

アプリには依存パッケージがありません。Node.jsの標準ライブラリだけで次を実行できます。

    node tests/core.test.cjs
    node tests/editor.test.cjs
    node tests/media-controller.test.cjs
    node tests/workflow.test.cjs
    node tests/readability.test.cjs

コア17項目・編集ハンドラー21項目・再生／書出し制御24項目・工程UI81項目・文字表示の静的検査7項目、計150項目を検証しました。編集検証はDOM・媒体のシミュレーションであり、ブラウザAPIを実行していません。詳細と残項目は [検証記録](VALIDATION.md)、Claude Opus 5.5によるコードレビューと対応は [レビュー記録](REVIEW.md) にあります。

prototype.html は実機用の最小12秒診断です。アプリ本体の素材読込・同期の合格を示すものではありません。
