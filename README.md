# AI Video Maker

操作録画に、場面別のWAV・字幕・拡大・強調を付ける日本語のローカル動画編集アプリです。実行に必要なのは **index.html 1ファイル**です。CDN、外部API、外部フォント、テレメトリ、サーバー、インストールは使いません。

**実験版です。実ブラウザでの動画書き出しは未検証です。** 自動ブラウザのローカルファイルアクセス制限により、12秒の実機試験を実施できていません。社内Edge、Snipping Toolの実MP4、実VOICEVOX WAV、Clipchamp変換、90秒の同期は受入確認が必要です。自動検証を実機合格と扱わないでください。

## 使い始める

1. ZIPを展開し、index.html をMicrosoft Edgeで開きます。
2. 「初めての方へ・12秒の動作確認」を開き、「合成デモを作る（12秒）」で2場面の合成素材を生成します。別途生成された録画とWAVも保存します。
3. ④でプレビューし、音声付き動画を書き出します。白いマーカーと短音・字幕・拡大・場面切替を確認します。
4. 試験が通ってから、実際のSnipping Tool MP4とVOICEVOX WAVで同じ試験を行います。MP4が出せない場合はWebMを選び、Clipchampで取込とMP4変換を確認します。
5. 通常の作業は [利用手順](USER_GUIDE.md) を参照してください。確認記録は [受入チェック](ACCEPTANCE.md) に残してください。

## 4つの工程

1. 録画：大きな「録画ファイルを選ぶ」から開始。動画の目的と代表画像を用意します。位置調整・領域指定は必要なときに開きます。
2. 構成：CopilotのJSONを取り込み、場面とナレーションを編集します。
3. 音声：VOICEVOX用台本をコピーし、場面ごとのWAVを対応付けます。
4. 書き出し：プレビューと準備状況を確認し、動画を保存します。

「前の作業を開く」は編集データJSONの再開用です。自動保存はありません。JSONのダウンロード開始と実際の端末への保存は別のため、ブラウザーで保存結果を確認してください。動画・WAVと、Copilot依頼用の目的・視聴者・希望尺はJSONに含まれません。

## 実装範囲

- 3秒間隔と指定時刻の代表画像、最大48枚、6枚ずつのPNG一覧
- 社内Microsoft 365 Copilotへ手動添付する依頼文と、編集案JSONの検証
- IDによる場面別WAV対応、重複確認・手動対応・試聴
- 元動画の開始／終了ボタン、±0.1／±1秒、字幕・領域編集、並べ替え・削除・取消
- ナレーション変更時の音声再生成状態、字幕はみ出し検知
- AudioContext主時計、2つの動画要素による次場面準備、共通Canvas描画
- CanvasとWeb AudioをMediaRecorderへ渡す実時間書き出し
- MP4優先候補とWebM、実MIMEに合う拡張子、出力後の映像デコード確認
- プロジェクトJSON保存・復元、素材の再選択とメタデータ照合

映像と音声の長さを比べ、場面尺は max(映像長, 0.15秒＋WAV長＋0.25秒) です。録画元音声は合成しません。WAVの無音も長さに含みます。

動画の読込・シーク・コーデック・MediaRecorderの対応は端末に依存します。フレーム欠落ゼロ、フレーム単位編集、±150msの同期を保証するものではありません。保存前のデコード確認は映像が読めることの確認であり、音声の聴取確認やClipchamp互換確認の代替にはなりません。

## 開発と検証

アプリには依存パッケージがありません。Node.jsの標準ライブラリだけで次を実行できます。

    node tests/core.test.cjs
    node tests/editor.test.cjs
    node tests/media-controller.test.cjs
    node tests/workflow.test.cjs

コア17項目・編集ハンドラー21項目・再生／書出し制御13項目・工程UI20項目、計71項目を検証しました。編集検証はDOM・媒体のシミュレーションであり、ブラウザAPIを実行していません。詳細と残項目は [検証記録](VALIDATION.md)、Claude Opus 5.5によるコードレビューと対応は [レビュー記録](REVIEW.md) にあります。

prototype.html は実機用の最小12秒診断です。アプリ本体の素材読込・同期の合格を示すものではありません。
